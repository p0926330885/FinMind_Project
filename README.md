# FinMind_Project

台股自訂板塊盤後法人資金儀表板。

## 線上入口

- 儀表板首頁：`https://p0926330885.github.io/FinMind_Project/`
- 直接開啟儀表板：`https://p0926330885.github.io/FinMind_Project/dashboard.html`
- 使用說明：`https://p0926330885.github.io/FinMind_Project/guide.html`

## 主要功能

- 16 個自訂板塊
- 三大法人淨流入
- 挹注強度（淨流入 ÷ 成交值）
- 近 20 日異常度 z
- 近 20 日資金輪動播放
- 板塊內部資金分歧光暈
- 點擊板塊查看外資、投信與成分股明細

## 資料更新

GitHub Actions 於台灣時間週一至週五 15:30 自動執行管線，產生 `data/bubble_data.json`。
